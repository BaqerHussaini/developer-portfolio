Heart Disease Prediction

A clinical risk model built with Python and scikit-learn

The project compares multiple classifiers and prioritizes recall so high-risk patients are not missed.

Overview

This project uses the Cleveland UCI Heart Disease dataset (303 patients, 13 features) to predict heart disease risk from clinical metrics such as age, blood pressure, cholesterol, and heart rate. The focus is on feature engineering and on evaluating models properly instead of relying on a single accuracy number.

Tools

Python · NumPy · pandas · matplotlib · seaborn · scikit-learn · Jupyter · Git/GitHub

Process

The work is split into notebooks, one per stage:

  • Data exploration: checked class balance, compared features such as sex, chest pain type, and max heart rate against the target, and plotted a correlation heatmap
  • Train/test split 80% training (242 samples), 20% testing (61 samples)
  • Model comparison: trained KNN, Logistic Regression, and Random Forest
  • Hyperparameter tuning: tuned KNN, Logistic Regression, and Random Forest with RandomizedSearchCV and GridSearchCV
  • Evaluation: ROC curve and AUC, confusion matrix, classification report, and 5-fold cross-validation
  • Feature importance: read the Logistic Regression coefficients to see which features drive predictions

Results

Model Test accuracy
KNN (tuned) 75.4%
Random Forest (tuned) 86.9%
Logistic Regression (tuned) 88.5%

Logistic Regression was the best model. Under 5-fold cross-validation it averaged 84.8% accuracy, 82.2% precision, 92.7% recall, and 87.1% F1. On the test set it made 7 mistakes out of 61 patients (4 false negatives and 3 false positives). The model fell short of the 95% accuracy target set for the project, which is a useful reminder that a strong recall score can still come with meaningful trade-offs.

Chest pain type and the exercise ST-segment slope pushed predictions toward heart disease, while sex pushed away from it. That matches the data, where women in this dataset were far more likely to be positive than men.

What This Project Demonstrates

  • Why a train/test split matters, and how cross-validation gives a more honest score than a single split
  • How to tune hyperparameters with RandomizedSearchCV and GridSearchCV
  • How to evaluate beyond accuracy, using precision, recall, F1, ROC/AUC, and a confusion matrix
  • Why recall matters in a medical problem, where missing a sick patient is worse than a false alarm
  • How to read model coefficients to see what a model learned
